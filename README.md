# بسته کاهش مصرف توکن برای Claude Code

این پروژه یک «بسته تنظیمات» کوچک است که باعث می‌شود Claude Code هنگام کار، توکن کمتری مصرف کند. هیچ دانش فنی برای استفاده لازم نیست.

## این بسته شامل چیست؟

| فایل | کارش چیست |
|---|---|
| `CLAUDE.md` | به Claude می‌گوید کوتاه جواب بده، فایل‌ها را الکی دوباره نخواند و حرف اضافه نزند. (بیشترین صرفه‌جویی) |
| `.claude/settings.json` | تماس‌های غیرضروری مدل را خاموش و خروجی ابزارها را محدود می‌کند. |

## چقدر توکن کم می‌کند؟

واقع‌بینانه بین **۱۵٪ تا ۴۰٪**. این یک معجزه نیست، یک بهینه‌سازی واقعی است.

## چطور در پروژه‌های دیگرم استفاده کنم؟

هر پروژه دیگری را در `claude.ai/code` باز کن و متن داخل فایل `INSTALL-PROMPT.md` را در چت کپی-پیست کن. Claude همان پروژه، خودش این فایل‌ها را می‌سازد. تمام.
